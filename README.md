# Amey Thakare — Delivered

Personal portfolio. Plain HTML, CSS and JavaScript with no build step.

## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. In Vercel, choose Add New > Project, import the repo, keep Framework Preset as "Other", and deploy.

## Edit content
All text lives in the `<script>` block near the bottom of `index.html` (`seasons`, `originals`, `leadership`, `genres`, `awards`, `trailer`).
Swap the photo in `assets/portrait-*.webp` and the resume in `assets/Amey_Thakare_Resume.pdf`.
